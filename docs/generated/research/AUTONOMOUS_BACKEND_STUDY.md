# Autonomous Backend Study System

The backend maintains a continuously updateable research workflow:

DISCOVER
→ DECOMPOSE
→ COLLECT
→ COMPARE
→ VALIDATE
→ STORE
→ QUESTION
→ REVISIT
→ LEARN

Knowledge records contain:

- subject
- topic
- summary
- evidence
- confidence
- assumptions
- open questions
- validation status
- update timestamp

The system must distinguish:

FACT
MEASURED DATA
PEER-REVIEWED RESULT
MODEL OUTPUT
HYPOTHESIS
INFERENCE
SPECULATION
UNKNOWN

External information requires an authorized data source, API, search
connector, uploaded document, database, or other available input.

The system must not invent research evidence when no source is available.
