# Book Writing System

Flow:

IDEA
→ RESEARCH
→ OUTLINE
→ CHAPTER PLAN
→ DRAFT
→ REVIEW
→ FACT CHECK
→ REVISION
→ CONSISTENCY CHECK
→ FINAL MANUSCRIPT
→ SAVE

The system can structure and save books as Markdown and JSON.

Research-based books should distinguish verified facts, sources,
interpretations, hypotheses and fictional/creative content.

The writing engine does not automatically claim facts are true merely
because they were generated.
