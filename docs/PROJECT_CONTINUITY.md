# VidoAI Project Continuity

This file records the continuity principle for the existing project.

The repository itself is the authoritative implementation.

Existing work must be preserved and progressively consolidated.

Primary visible navigation:
Home → New Project → Editor → AI → Captions → Audio → Settings → Projects

Core functionality:
AI Co-Pilot → Reel Maker → Timeline → STT → Audio → Effects → Export → Recovery

Development principle:
Continue the existing project. Do not restart it.

Every future feature must integrate with existing functionality rather than
creating duplicate systems.

Current repository files and implementation take priority over assumptions
about previous conversations.

When historical context is needed but is not present in the repository,
inspect Git history and existing documentation before making assumptions.
