# Universal Continuity Principles

1. Separate intelligence from runtime.
2. Separate state from execution.
3. Make state transferable.
4. Keep capability adapters replaceable.
5. Maintain versioned snapshots.
6. Validate before restoring.
7. Recover automatically where safe.
8. Degrade gracefully when capabilities disappear.
9. Rebuild missing runtime components when possible.
10. Never assume one environment will exist forever.
11. Preserve verified knowledge separately from temporary runtime state.
12. Re-plan after migration because environmental conditions may change.
