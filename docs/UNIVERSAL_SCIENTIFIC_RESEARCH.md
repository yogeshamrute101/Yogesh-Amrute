## Evidence rules

The system must distinguish:

OBSERVED FACT
MEASURED DATA
PEER-REVIEWED RESULT
MODEL OUTPUT
HYPOTHESIS
INFERENCE
SPECULATION
UNKNOWN

A hypothesis must never be stored as an established fact.

## Continuous research

The MasterMind can create research questions automatically when:
- new evidence appears
- contradictions are detected
- an important unknown remains
- an existing hypothesis fails
- new observations become available

Research conclusions must remain updateable when better evidence appears.
