# Universal Correlation Intelligence

## Purpose

Understand relationships and recurring patterns between observations,
events, variables, systems, activities and outcomes.

## Types

- Statistical
- Temporal
- Sequential
- Behavioral
- Dependency
- Spatial
- Semantic
- Event
- Multimodal
- Historical

## Core process

OBSERVATIONS
-> ALIGN
-> DETECT PATTERN
-> MEASURE
-> CHECK DIRECTION
-> CHECK TIME LAG
-> CHECK REPLICATION
-> CHECK CONFOUNDERS
-> ESTIMATE CONFIDENCE
-> STORE EVIDENCE

## Statistical correlation

For numeric observations the system can estimate a Pearson-style
correlation coefficient.

The coefficient indicates direction and strength of linear association,
not causation.

## Temporal correlation

The system can detect whether events repeatedly occur within a defined
time window and measure the observed time lag.

## Multimodal correlation

Events from:

IMAGE
+ AUDIO
+ VIDEO
+ SENSOR
+ TEXT
+ ACTIVITY

can be aligned on a shared timeline to discover relationships.

## Causation boundary

A correlation may be:

A associated with B

without:

A causing B.

Causal reasoning requires additional evidence such as temporal order,
mechanistic explanation, controlled experiments, natural experiments,
or other appropriate causal methods.

## Learning

Verified correlation patterns can be passed to:

- Experience Intelligence
- Causal Reasoning
- Future Intelligence
- Statistics
- Action-Reaction
- Output Learning

for further analysis.
