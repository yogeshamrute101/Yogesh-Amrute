# Universal Movement Understanding

## Meaning

Movement is represented as change across space, state, time, order,
workflow or resources.

## Domains

PHYSICAL, HUMAN, ROBOT, OBJECT, FILE, DATA, NETWORK, RESOURCE,
PROJECT, WORKFLOW, GAME, TIME and STATE.

## Examples

Physical:
A robot moves from one position to another.

Digital:
A file moves from one folder to another.

Data:
Data transfers from one system to another.

Project:
A task moves from PLANNED to BUILDING to VERIFIED.

Workflow:
An operation moves from one stage to the next.

State:
A system changes from ACTIVE to PAUSED.

## Understanding

DETECT
-> TRACK
-> IDENTIFY
-> MEASURE
-> UNDERSTAND
-> PREDICT
-> ACT
-> OBSERVE
-> VERIFY
-> LEARN

## Prediction

Historical movement patterns can be used to estimate possible next
states, but prediction remains probabilistic and must not be treated
as certainty.

## Physical control

Understanding movement does not automatically grant physical control.
Actual movement requires authorized hardware, sensors, actuators and
appropriate safety controls.
