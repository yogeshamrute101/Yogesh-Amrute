# Universal Multimodal Understanding & Creation Center

## Purpose

Provide one common architecture for understanding and creating across
text, images, camera streams, audio, video, maps and documents.

## Knowledge domains

Design, layout, maps, tracking, graphics, geometry, activity,
chemistry, psychology, history, knowledge, dictionaries, languages
and media.

## Media understanding

CAMERA
-> FRAME ANALYSIS
-> OBJECT/EVENT DETECTION
-> TRACKING
-> ACTIVITY UNDERSTANDING

AUDIO
-> SIGNAL ANALYSIS
-> SPEECH/SOUND DETECTION
-> TRANSCRIPTION
-> TIMELINE

VIDEO
-> FRAME ANALYSIS
-> AUDIO ANALYSIS
-> SCENE SEGMENTATION
-> ACTION/TRACKING
-> MULTIMODAL TIMELINE

## Reality boundary

This architecture does not automatically contain every dictionary,
Wikipedia article, scientific database, language model, camera driver,
codec or animation model.

Those capabilities require authorized connectors, datasets, parsers,
models and rendering infrastructure.

The system should distinguish verified knowledge from inference,
prediction and unknown information.
