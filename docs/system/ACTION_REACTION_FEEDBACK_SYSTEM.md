# Action–Reaction–Feedback System

## Core loop

INPUT
-> UNDERSTAND
-> PREDICT
-> ACT
-> OBSERVE REACTION
-> COMPARE
-> VERIFY
-> CORRECT/ADAPT
-> LEARN
-> NEXT ACTION

## Expected vs actual

The system stores both the predicted/expected reaction and the actual
observed reaction.

This allows it to identify:

- expected outcomes
- positive outcomes
- negative outcomes
- neutral outcomes
- unexpected outcomes
- errors
- unknown outcomes

## Adaptive behavior

Expected and verified outcomes can continue the plan.

Unexpected outcomes trigger re-planning.

Errors or unsafe outcomes can trigger correction, stop or human review.

## Learning

Verified action-reaction pairs become evidence for future planning and
prediction.

## Boundary

A reaction is not automatically interpreted as causation. The system
should distinguish correlation, observed response and demonstrated
causal effect.
