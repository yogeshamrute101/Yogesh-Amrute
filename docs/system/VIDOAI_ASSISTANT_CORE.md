## Important

This is an assistant orchestration layer, not a copy of OpenAI's proprietary model or weights.

Actual language intelligence can be supplied by an authorized AI model/provider.
The orchestration layer controls context, reasoning workflow, project awareness,
verification, permissions, and safe execution.
