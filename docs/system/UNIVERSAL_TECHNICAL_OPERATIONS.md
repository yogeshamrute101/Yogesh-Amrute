# Universal Technical Operations

## Scope

A common orchestration layer for technical work across:

- Software
- Hardware
- IT
- Networking
- Cloud
- DevOps
- Databases
- AI/ML
- Data
- Cybersecurity
- Electronics
- Embedded systems
- Automation
- Robotics
- Systems
- Engineering tools
- Testing
- Debugging
- Performance
- UI/UX
- Media technology
- APIs and integrations
- Documentation
- Monitoring
- Recovery

## Operation lifecycle

DISCOVER
→ INSPECT
→ ANALYZE
→ PLAN
→ EXECUTE
→ TEST
→ VERIFY
→ DOCUMENT
→ MONITOR
→ RECOVER
→ LEARN

## Execution policy

The layer coordinates operations but does not automatically grant access
to computers, accounts, networks, devices, cloud systems, financial systems,
or physical equipment.

Actual execution requires an appropriate registered tool, API, driver,
credential, permission and safety policy.

High-impact or destructive operations require explicit authorization.

## Verification

A technical operation is not considered complete merely because code or
configuration was generated.

Completion requires appropriate evidence such as:

- successful tests
- build results
- runtime checks
- measurements
- logs
- simulations
- validation results
- human review where required
