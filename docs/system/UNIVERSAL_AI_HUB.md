# Universal AI Hub

Provides one orchestration interface for:

- Chat assistant
- Coding assistant
- Debugging
- Research
- Document intelligence
- Creative tasks
- Video intelligence
- Planning
- Automation
- System operations

The hub supports authorized provider adapters such as local or cloud AI
providers. It does not reproduce proprietary model weights, code, or
internal implementations.

Provider selection is separated from application capabilities so the
existing VidoAI Assistant Core, MasterMind, Research, Engineering,
Technical Operations and Video systems can use the same AI interface.

High-impact actions can require explicit approval.
