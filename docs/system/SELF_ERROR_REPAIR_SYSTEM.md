# Self Error Understanding & Repair System

The system follows:

DETECT
→ UNDERSTAND
→ DIAGNOSE
→ PLAN
→ SAFE FIX
→ TEST
→ VERIFY
→ LEARN
→ REPORT

Principles:

- Inspect evidence before changing code.
- Identify the root cause instead of blindly patching symptoms.
- Prefer the smallest safe change.
- Preserve working functionality.
- Verify every repair.
- Record successful and failed repair attempts.
- High-risk changes require human approval.
- Never claim a repair succeeded without verification.

The system is project-aware and can use existing diagnostics, RCA,
CAPA, engineering context, QA, audit, safety and continuous-loop
capabilities.
