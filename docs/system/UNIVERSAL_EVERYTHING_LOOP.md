# Universal Everything Loop

## Core loop

OBSERVE
-> UNDERSTAND
-> REMEMBER
-> RESEARCH
-> REASON
-> PLAN
-> EXECUTE
-> MONITOR
-> VERIFY
-> CORRECT
-> LEARN
-> STORE
-> ADAPT
-> REPEAT

## Integration

The loop is designed to connect the existing system layers:

Memory
Research
MasterMind
Planning
Operations
Verification
RCA
CAPA
Learning
Continuity
Heartbeat
Audit

## Verification

If verification fails, the loop enters CORRECT and then retries the
controlled cycle.

## Safety

The loop does not bypass authorization, safety, resource limits or
external system permissions.

## Termination

A task stops when its required result is verified, the user stops it,
a configured iteration/resource limit is reached, or safe mode is
required.

This creates continuous improvement without uncontrolled infinite
execution.
