# VidoAI Research & Project Builder Center

## 1. Running Research Center

Continuous research workflow:

DISCOVER
→ COLLECT
→ VERIFY
→ SYNTHESIZE
→ STORE
→ UPDATE
→ REPORT

Research distinguishes:

- VERIFIED
- EVIDENCE
- INFERENCE
- HYPOTHESIS
- SIMULATION
- UNKNOWN

The center can maintain multiple research projects.

## 2. Project Builder Center

Project lifecycle:

DISCOVERY
→ REQUIREMENTS
→ ARCHITECTURE
→ BUILD
→ TEST
→ VERIFY
→ DEPLOY
→ MONITOR
→ IMPROVE

Projects can contain dependency-aware build tasks.

## 3. Research → Project Pipeline

RESEARCH
→ VERIFIED FINDINGS
→ REQUIREMENTS
→ ARCHITECTURE
→ BUILD
→ TEST
→ INDEPENDENT VERIFICATION
→ PROJECT

## 5. Important boundary

Creating the architecture does not automatically grant access to the internet,
cloud accounts, repositories, devices, paid APIs or deployment infrastructure.

Those require explicit adapters, authentication, authorization and appropriate
human approval.
