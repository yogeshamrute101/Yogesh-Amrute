# Universal Experience Intelligence

## Purpose

Experience converts verified past activity and outcomes into reusable
evidence for future decisions.

## Core loop

PAST ACTIVITY
-> RESULT
-> VERIFY
-> ANALYZE
-> LESSON
-> EXPERIENCE MEMORY
-> PATTERN
-> NEXT DECISION
-> ACTION
-> RESULT
-> VERIFY
-> UPDATE

## Experience memory

Each record can contain:

- situation
- action
- result
- outcome
- verification
- errors
- lessons
- timestamp
- domain
- metadata

## Decision use

When a new situation appears:

NEW SITUATION
-> SEARCH SIMILAR EXPERIENCE
-> CHECK DIFFERENCES
-> CHECK VERIFICATION
-> IDENTIFY SUCCESSFUL PATTERNS
-> IDENTIFY FAILED PATTERNS
-> SELECT APPLICABLE EXPERIENCE
-> ACT
-> VERIFY

## Important rule

Experience is not automatically truth.

An old successful action can become wrong when the environment,
requirements, tools or conditions change. Therefore experience must
be combined with current evidence, verification, uncertainty and
context.

## Learning from failure

FAILURE
-> ROOT CAUSE
-> CORRECTIVE ACTION
-> PREVENTIVE ACTION
-> VERIFY
-> STORE LESSON

This allows the system to reduce repeated errors over time.
