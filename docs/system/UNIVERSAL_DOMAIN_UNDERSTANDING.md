# Universal Domain Understanding Center

The system provides a common architecture for understanding scientific,
office, software, file, network and world-context information.

## Domains

Geometry, physics, chemistry, mathematics, symbols, Excel/spreadsheets,
Word/documents, PDF, presentations, PPD, templates, files, folders,
software, APIs, networks, connections and world context.

## Common pipeline

INPUT
-> IDENTIFY DOMAIN
-> PARSE STRUCTURE
-> UNDERSTAND
-> RELATE
-> VERIFY
-> TRANSFORM
-> VALIDATE
-> OUTPUT
-> TRACE

## Important boundary

Creating the architecture does not mean the system already contains
every formula, world fact, Office template, software API or network
protocol. Those require populated knowledge bases, parsers, connectors,
validated formulas and authorized integrations.

Network/device operations require authentication and authorization.
Destructive file/software operations require explicit permission.
