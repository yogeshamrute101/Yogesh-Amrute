# Universal Editing System

A common editing layer for the existing VidoAI and future system
capabilities.

Domains:
- Text and documents
- Source code
- Images and video
- Audio
- Captions
- Projects and files
- Structured data

Workflow:

REQUEST
→ PREVIEW
→ VALIDATE
→ APPROVE WHEN REQUIRED
→ APPLY
→ VERIFY
→ RECORD
→ RECOVER IF NEEDED

The layer does not replace existing editors. It provides a common
orchestration interface for them.

Destructive changes require additional validation/approval.
Original state should be preserved whenever technically possible.
