# Human Skills & Creative Performance System

The system can learn about, teach, analyze and plan practice for human
skills including:

- Dancing
- Singing
- Music
- Playing games and sports
- Acting
- Drawing and painting
- Writing
- Public speaking
- Cooking
- Crafts
- Fitness
- Languages
- Creative performance

Workflow:

OBSERVE
→ UNDERSTAND
→ LEARN
→ PRACTICE
→ MEASURE
→ FEEDBACK
→ ADAPT
→ IMPROVE

Actual physical performance requires an appropriate human, camera,
sensor, audio, robotics or other physical interface. The software does
not claim a physical body or human consciousness.
