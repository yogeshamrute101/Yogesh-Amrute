# Human Capability System

The Human Capability System provides a unified capability model for digital
and assisted human workflows.

## Domains

- Thinking and reasoning
- Learning and research
- Reading and writing
- Communication
- Coding and software development
- Creation and media
- Analysis and calculation
- Planning and organization
- Files and project management
- Scheduling
- Translation
- Teaching
- Accessibility
- Web and software workflows
- Automation
- Device interaction
- Physical-world assistance

## Execution model

OBSERVE
→ SUGGEST
→ REQUEST APPROVAL
→ EXECUTE
→ VERIFY
→ RECORD
→ LEARN

## Safety boundary

The system does not receive unrestricted authority.

External accounts, financial actions, sensitive information,
high-impact decisions, physical-world actions, and destructive operations
must remain permission-controlled.

Capability registration does not mean the underlying integration exists.
A capability becomes operational only after its required tool/API/device
integration is available and verified.
