# Universal Law & Rules System

Provides a rule-based governance layer for system decisions.

Rule levels:
- System
- Safety
- Privacy
- Security
- Legal
- Regulatory
- Project
- User

Decision flow:

REQUEST
→ RULE CHECK
→ SAFETY CHECK
→ LEGAL/REGULATORY CHECK
→ APPROVAL OR BLOCK
→ EXECUTION
→ AUDIT

System rules are not a replacement for the laws of a jurisdiction.
Current legal and regulatory requirements must be verified against
authoritative sources.

Higher-priority safety and legal restrictions cannot be bypassed by
ordinary user preferences or application logic.
