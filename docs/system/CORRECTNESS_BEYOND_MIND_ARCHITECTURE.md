# VidoAI Correctness & Beyond-Mind Architecture

## Objective

Create a measurable verification architecture rather than claiming perfect
accuracy or consciousness.

## Truth states

- VERIFIED
- UNVERIFIED
- INFERRED
- PREDICTED
- SIMULATED
- HYPOTHESIS
- UNKNOWN
- CONFLICTING
- REQUIRES_HUMAN_REVIEW

## Correctness target

0.9999 is treated as a target threshold for applicable verified
operations, never as a universal guarantee.

The system must measure real results instead of declaring accuracy.

## Metrics

correctness =
verified_correct / total_verified_cases

reliability =
successful_verified_operations / total_operations

regression_rate =
previously_fixed_failures_reappearing / regression_tests

unknown_rate =
correctly_declared_unknown / genuinely_unknown_cases

## Safety rule

Critical medical, engineering, financial, physical-world and other
high-impact operations require appropriate authorization and qualified
human review. Higher confidence never removes safety requirements.

## Integration rule

A source file existing does NOT mean that the capability is integrated.

Each capability must progress through:

MISSING
→ PLANNED
→ BUILDING
→ INTEGRATED
→ TESTING
→ VERIFIED
→ PRODUCTION
