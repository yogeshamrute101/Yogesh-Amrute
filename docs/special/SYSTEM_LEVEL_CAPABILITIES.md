# System-Level Capabilities

Special architecture layers:

1. System Constitution
2. Self Diagnostics
3. Root Cause Analysis
4. Corrective and Preventive Action (CAPA)
5. Knowledge Graph
6. Capability Registry
7. Goal and Mission Management
8. Canary Testing
9. Explainability
10. Universal Event Bus
11. Reality Boundary
12. Closed-Loop Improvement

Core improvement cycle:

DETECT
→ DIAGNOSE
→ PLAN
→ CORRECT
→ PREVENT
→ TEST
→ VERIFY
→ LEARN
→ MONITOR

Important boundary:

A software framework existing in the repository does not mean that the
corresponding real-world capability is operational. Capabilities must be
integrated, tested and verified before being marked verified or production.
External systems and physical actions require appropriate authorization,
authentication and infrastructure.
