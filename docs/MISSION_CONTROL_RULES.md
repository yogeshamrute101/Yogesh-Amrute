# Mission Control Rules

1. Every mission needs an objective.
2. Every objective needs measurable success criteria.
3. Every mission needs milestones.
4. Dependencies must be explicit.
5. Known risks need mitigations.
6. Resources must be checked before execution.
7. Simulation should precede high-risk execution when possible.
8. Telemetry must be recorded during active operations.
9. Anomalies must trigger evaluation.
10. Recovery must be planned before execution.
11. Completed missions must produce lessons learned.
12. Lessons must return to the research and planning systems.
