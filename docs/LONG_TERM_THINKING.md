# VidoAI Long-Term Thinking System

The system must not reason only about the current event.

It should continuously consider:

CURRENT STATE
    ↓
HISTORY
    ↓
GOALS
    ↓
DEPENDENCIES
    ↓
RISKS
    ↓
OPPORTUNITIES
    ↓
POSSIBLE FUTURES
    ↓
ACTIONS
    ↓
EXPECTED CONSEQUENCES
    ↓
VERIFY
    ↓
UPDATE PLAN

## Planning horizons

SHORT_TERM
- immediate actions
- minutes/hours/days

MEDIUM_TERM
- weeks/months
- project milestones

LONG_TERM
- months/years
- strategic goals
- accumulated consequences

FUTURE
- alternative future scenarios
- uncertainty
- contingency planning

## Long-term reasoning rules

1. Remember relevant historical context.
2. Consider consequences beyond the immediate action.
3. Track dependencies between goals and actions.
4. Detect future risks early.
5. Identify opportunities.
6. Prefer reversible actions when uncertainty is high.
7. Re-evaluate plans when new evidence appears.
8. Never treat a prediction as a guaranteed future fact.
9. Preserve uncertainty explicitly.
10. Learn only from verified outcomes.
