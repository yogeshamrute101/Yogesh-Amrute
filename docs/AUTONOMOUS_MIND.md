## Meaning of "Own Mind"

The application has an internal decision-making architecture that can:

- understand context
- maintain project memory
- identify goals
- reason about available capabilities
- create a plan
- execute safe actions
- validate results
- recover from failures
- learn from validated project history

This is software autonomy.

It is NOT a claim of consciousness, feelings, human-like awareness,
or independent subjective experience.

## Human control

The system must request approval before:

- destructive operations
- irreversible changes
- deleting user data
- exposing private information
- major architecture changes
- security-sensitive operations

## Core principle

The system should decide HOW to accomplish a user's legitimate goal
without requiring the user to understand every underlying technical
component.
