# VidoAI Agent Platform

Native n8n-style automation layer for VidoAI.

## Architecture

Prompt
→ Planner
→ Workflow
→ Nodes
→ Runtime
→ Verification/Recovery
→ Result

## Planned node families

- Trigger
- AI Agent
- LLM
- Research
- HTTP/API
- File
- Transform
- Condition
- Loop
- Memory
- Human Approval
- Video
- Captions
- Audio
- Timeline
- Export
- Output

The platform is designed as an additive layer over the existing VidoAI editor and Universal Core.
